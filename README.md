## 사용법

```
pip install -r requirements.txt
python riot_friend_notifier.py
```

처음 실행하면 같은 폴더에 `config.json`이 만들어지고 종료됩니다. 내용을 채운 뒤 다시 실행하세요.

```json
{
  "friends": ["알퐁스#태그"],
  "discord_webhook_url": "https://discord.com/api/webhooks/...",
  "interval_seconds": 10,
  "ignore_mobile": true
}
```

| 항목 | 설명 |
|---|---|
| `friends` | 감시할 사람 목록. `닉네임#태그` 또는 닉네임만 |
| `discord_webhook_url` | 알림을 보낼 웹훅 주소. 비워두면 콘솔에만 출력 |
| `interval_seconds` | 확인 간격(초) |
| `ignore_mobile` | 라이엇 모바일 앱 접속을 온라인으로 치지 않음 |

현재 보이는 유저 상태를 그대로 확인하려면:

```
python riot_friend_notifier.py --dump
```

## 동작 방식

1. 라이엇 클라이언트가 만드는 `lockfile`에서 로컬 API의 포트와 비밀번호를 읽음
2. `https://127.0.0.1:{포트}/chat/v4/presences`에서 친구목록 상태 조회
3. presence의 `private` 필드(base64 JSON)에서 게임 상태와 큐 종류(`queueId`)를 읽음
4. 이전 상태와 비교해 바뀌었으면 디스코드 웹훅으로 전송
