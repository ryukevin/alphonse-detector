#퐁스롤 감지기

퐁퐁스가 온라인이 되면 디스코드로 알려줘요

내 PC에서 실행 중인 라이엇 클라이언트의 로컬 API에서 친구 상태를 주기적으로 읽고, 지정한 친구의 상태가 바뀌면 디스코드로 메시지를 보내주는 퐁스롤 감지기입니다. ^^7

알퐁스 롤켜라
```
🟢 알퐁스#3497 접속! (라이엇 클라이언트, 롤)
🔄 알퐁스#3497 상태 변경: 라이엇 클라이언트, 롤 솔로랭크 게임 중
⚫ 알퐁스#3497 오프라인
```

실행하면 감시 대상들의 현재 상태를 디스코드로 한 번 보내고, 그 뒤로는 바뀔 때만 보내요.

게임 중이면 큐 종류도 같이 보여줘요. 로비, 큐 대기, 챔피언 선택은 알림을 보내지 않고 실제 게임이 시작/종료될 때만 보내요.

- 롤: 솔로랭크, 자유랭크, 일반, 신속 대전, 빠른 대전, 칼바람, 우르프, 아레나, TFT
- 발로란트: 경쟁전, 일반전, 신속 플레이, 스파이크 돌격, 데스매치 등

## 필요한 것

- Windows, Python 3.8 이상
- 라이엇 클라이언트 (켜져 있고 로그인된 상태)
- 알퐁스가 친구추가 되어있어야함
- 디스코드 웹훅 URL (알림 받을 채널 설정 > 연동 > 웹후크)

## 사용법

```
pip install -r requirements.txt
python riot_friend_notifier.py
```

처음 실행하면 같은 폴더에 `config.json`이 만들어지고 종료됩니다. 내용을 채운 뒤 다시 실행하세요.

```json
{
  "friends": ["닉네임#태그"],
  "discord_webhook_url": "https://discord.com/api/webhooks/...",
  "interval_seconds": 10,
  "ignore_mobile": true
}
```

| 항목 | 설명 |
|---|---|
| `friends` | 감시할 사람 목록. `닉네임#태그` 또는 닉네임만 |
| `discord_webhook_url` | 알림을 보낼 웹훅 주소. 비워두면 콘솔에만 출력 |
| `interval_seconds` | 확인 간격(초) |
| `ignore_mobile` | 라이엇 모바일 앱 접속을 온라인으로 치지 않음 |

현재 보이는 유저 상태를 그대로 확인하려면:

```
python riot_friend_notifier.py --dump
```

## 동작 방식

1. 라이엇 클라이언트가 만드는 `lockfile`에서 로컬 API의 포트와 비밀번호를 읽음
2. `https://127.0.0.1:{포트}/chat/v4/presences`에서 친구목록 상태 조회
3. presence의 `private` 필드(base64 JSON)에서 게임 상태와 큐 종류(`queueId`)를 읽음
4. 이전 상태와 비교해 바뀌었으면 디스코드 웹훅으로 전송

## 주의

- 이 프로젝트는 Riot Games와 무관하며, 공식 지원되지 않는 로컬 클라이언트 API를 사용합니다. 클라이언트 업데이트로 동작하지 않게 될 수 있습니다.
- 내 친구 목록에 이미 보이는 정보를 읽기만 하며, 게임 클라이언트를 수정하거나 조작하지 않습니다.
